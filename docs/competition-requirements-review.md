A deterministic Python chart is not automatically compliant simply because its pixels are rendered by code rather than an image model.

The existing AI-assisted report, code and figures are research materials. Editing a disclaimer, adding citations, changing formatting or lightly paraphrasing text cannot certify eligibility.
